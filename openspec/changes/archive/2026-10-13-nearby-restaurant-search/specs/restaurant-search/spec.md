# Spec Delta

## Purpose

사용자가 음식 종류나 식당 이름 같은 키워드로 식당을 찾고, 결과를 현재 위치 기준으로 목록과 지도에서 확인할 수 있게 한다.

## ADDED Requirements

### Requirement: 키워드 식당 검색
시스템은 사용자가 입력한 키워드로 식당을 검색하고 결과를 목록과 지도에 반영해야 한다(SHALL).

#### Scenario: 위치가 있을 때 검색
- **WHEN** 현재 위치를 알고 있는 상태에서 사용자가 "국밥"을 검색한다
- **THEN** 시스템은 현재 위치 반경 안에서 "국밥" 관련 식당을 거리순으로 목록과 지도에 표시한다

#### Scenario: 위치가 없을 때 검색
- **WHEN** 위치를 얻지 못한 상태에서 사용자가 키워드를 검색한다
- **THEN** 시스템은 위치 제한 없이 키워드와 일치하는 식당을 표시하고, 거리 정보는 표시하지 않는다

### Requirement: 빈 검색어 처리
시스템은 빈 검색어나 공백만 입력된 검색어로는 검색하지 않아야 한다(SHALL).

#### Scenario: 빈 입력
- **WHEN** 사용자가 검색어를 비우거나 공백만 입력하고 검색한다
- **THEN** 시스템은 검색을 요청하지 않고 입력을 요청하는 안내를 표시한다

### Requirement: 검색 결과 없음
시스템은 검색 결과가 없을 때 그 사실을 알려야 한다(SHALL).

#### Scenario: 결과 없음
- **WHEN** 검색어와 일치하는 식당이 없다
- **THEN** 시스템은 "검색 결과가 없어요"와 같은 안내를 표시한다

### Requirement: 검색 해제
시스템은 검색을 해제하고 주변 식당 목록으로 돌아갈 수 있게 해야 한다(SHALL).

#### Scenario: 검색 초기화
- **WHEN** 사용자가 검색어를 지우거나 초기화한다
- **THEN** 시스템은 현재 위치 기준 주변 식당 목록으로 돌아간다
