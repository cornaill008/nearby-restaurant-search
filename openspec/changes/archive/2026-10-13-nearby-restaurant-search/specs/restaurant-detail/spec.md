# Spec Delta

## Purpose

사용자가 선택한 식당의 기본 정보를 확인하고 전화나 지도 앱 등 다음 행동으로 쉽게 이어갈 수 있게 한다.

## ADDED Requirements

### Requirement: 식당 상세 정보 표시
시스템은 사용자가 식당을 선택하면 그 식당의 상세 정보를 보여야 한다(SHALL). 상세 정보에는 이름, 카테고리, 도로명 주소(없으면 지번 주소), 전화번호, 현재 위치로부터의 거리가 포함된다.

#### Scenario: 목록에서 식당 선택
- **WHEN** 사용자가 목록의 식당을 선택한다
- **THEN** 시스템은 해당 식당의 이름, 카테고리, 주소, 전화번호, 거리를 표시한다

#### Scenario: 일부 정보 없음
- **WHEN** 선택한 식당에 전화번호 등 일부 정보가 없다
- **THEN** 시스템은 없는 항목을 빈 값으로 두지 않고 숨기거나 "정보 없음"으로 표시한다

### Requirement: 외부 링크 제공
시스템은 상세 정보에서 해당 식당의 카카오맵 페이지로 이동하는 링크와, 전화번호가 있으면 전화 연결을 제공해야 한다(SHALL).

#### Scenario: 카카오맵 링크
- **WHEN** 사용자가 카카오맵에서 보기를 선택한다
- **THEN** 시스템은 해당 식당의 카카오맵 페이지를 새 창으로 연다

#### Scenario: 전화 연결
- **WHEN** 전화번호가 있는 식당에서 사용자가 전화를 선택한다
- **THEN** 시스템은 기기의 전화 걸기를 연다

### Requirement: 상세 정보 닫기
시스템은 사용자가 상세 정보를 닫고 목록으로 돌아갈 수 있게 해야 한다(SHALL).

#### Scenario: 상세 닫기
- **WHEN** 사용자가 상세 정보를 닫는다
- **THEN** 시스템은 선택 상태를 해제하고 이전 목록과 지도 상태를 유지한다
