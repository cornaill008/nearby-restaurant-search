# Proposal

## Why

개발 입문자가 포트폴리오로 남길 수 있는, 끝까지 동작하는 작은 서비스가 필요하다. "내 주변 식당 찾기"는 위치, 외부 API, 지도라는 웹 개발의 핵심 요소를 한 번에 연습할 수 있는 적당한 크기의 주제다. 현재 프로젝트에는 코드가 없어 처음부터 만든다.

## What Changes

- 한국 내 식당을 대상으로 하는 React + TypeScript + Vite 웹앱을 새로 만든다.
- 사용자의 현재 위치를 기준으로 주변 식당을 거리순 목록으로 보여준다.
- 지도에 식당 마커를 표시한다.
- 키워드로 식당을 검색한다 (예: "국밥", "파스타").
- 식당을 선택하면 상세 정보(이름, 주소, 전화번호, 카테고리, 카카오맵 링크)를 보여준다.
- 데이터와 지도는 카카오 로컬 API와 카카오맵을 사용한다.
- 위치 조회와 지도 렌더링은 교체 가능한 경계로 분리한다. 나중에 앱인토스(WebView 미니앱)에 올릴 때 SDK 위치 API나 다른 지도로 바꾸기 위해서다.
- 범위 밖: 로그인, 즐겨찾기, 리뷰와 평점 작성, 해외 지역, DB, 앱인토스 출시 자체(마지막 단계의 선택 과제).

## Capabilities

### New Capabilities
- `nearby-restaurants`: 현재 위치를 얻고 그 반경 안의 식당을 거리순 목록으로 보여준다 (위치 권한 거부와 결과 없음 처리 포함).
- `restaurant-map`: 지도에 현재 위치와 식당 마커를 표시하고 마커와 목록 항목을 서로 연동한다.
- `restaurant-search`: 키워드로 식당을 검색하고 결과를 목록과 지도에 반영한다.
- `restaurant-detail`: 선택한 식당의 상세 정보를 보여준다.

## Impact

- 새 코드베이스 생성: 웹앱 프로젝트 전체 (현재 `openspec/`만 존재).
- 외부 의존: 카카오 개발자 앱(JavaScript 키, 필요 시 REST API 키), 카카오맵 JS SDK, 카카오 로컬 API. 카카오 앱 설정에 웹 도메인(로컬 개발용 `localhost` 포함) 등록이 필요하다.
- 배포: 무료 정적 호스팅. 검색 호출을 서버로 중계해야 하면 서버리스 함수가 추가된다 (design에서 결정).
- 알려진 미확정 사항: 카카오 REST API를 브라우저에서 직접 호출할 수 있는지(JS SDK의 장소 검색 사용 가능성), 앱인토스 WebView에서 카카오맵 SDK가 로드되는지.
