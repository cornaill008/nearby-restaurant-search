# restaurant-map Specification

## Purpose

식당의 위치를 지도 위에서 한눈에 확인할 수 있게 하고, 지도와 목록이 서로 연동되어 탐색이 자연스럽도록 한다.

## Requirements

### Requirement: 지도에 현재 위치와 식당 마커 표시
시스템은 지도를 표시하고, 현재 위치와 목록에 있는 각 식당의 위치에 마커를 보여야 한다(SHALL).

#### Scenario: 주변 식당 마커 표시
- **WHEN** 주변 식당 목록이 표시된다
- **THEN** 지도는 현재 위치 마커와 목록의 각 식당 마커를 함께 보여주고, 모든 마커가 화면에 보이도록 범위를 맞춘다

#### Scenario: 목록 갱신 시 마커 갱신
- **WHEN** 목록이 새 결과로 바뀐다
- **THEN** 이전 마커는 제거되고 새 결과의 마커가 표시된다

### Requirement: 마커와 목록 연동
시스템은 지도의 마커와 목록의 항목을 서로 연동해야 한다(SHALL).

#### Scenario: 마커 선택
- **WHEN** 사용자가 지도의 식당 마커를 선택한다
- **THEN** 해당 식당이 선택 상태가 되고 목록에서 강조되며 상세 정보가 열린다

#### Scenario: 목록 항목 선택
- **WHEN** 사용자가 목록의 식당을 선택한다
- **THEN** 지도는 해당 식당 마커를 중심으로 이동하고 마커를 강조한다

### Requirement: 지도 표시 실패 시 대체 동작
시스템은 지도 표시에 실패해도 식당 목록, 검색, 상세 기능은 계속 사용할 수 있어야 한다(SHALL). 지도와 식당 검색은 같은 외부 SDK를 쓰므로, SDK 자체를 불러오지 못하면 식당 데이터도 불러올 수 없다.

#### Scenario: 지도 초기화 실패
- **WHEN** 지도 SDK는 불러왔지만 지도 생성에 실패한다
- **THEN** 시스템은 지도를 표시할 수 없음을 안내하고, 목록과 검색과 상세는 정상 동작한다

#### Scenario: SDK 로드 실패
- **WHEN** 지도 SDK 스크립트 자체를 불러오지 못한다
- **THEN** 시스템은 지도를 표시할 수 없음을 안내하고, 식당 목록도 불러오지 못했다는 오류 안내와 다시 시도 수단을 함께 보여준다

#### Scenario: 지도 다시 시도
- **WHEN** 지도 표시에 실패한 상태에서 사용자가 지도 다시 시도를 선택한다
- **THEN** 시스템은 지도 불러오기를 다시 시도하고, 성공하면 식당 마커를 표시한다
