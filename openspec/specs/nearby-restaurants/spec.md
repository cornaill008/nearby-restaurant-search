# nearby-restaurants Specification

## Purpose

사용자의 현재 위치를 기준으로 가까운 식당을 거리순 목록으로 보여주어, 검색어 없이도 주변 식당을 바로 찾을 수 있게 한다.

## Requirements

### Requirement: 현재 위치 기반 주변 식당 목록
시스템은 사용자의 현재 위치를 얻은 뒤 그 위치 반경 안의 식당을 가까운 순서로 목록에 표시해야 한다(SHALL). 기본 반경은 1km로 한다.

#### Scenario: 위치 허용 시 주변 식당 표시
- **WHEN** 사용자가 위치 권한을 허용하고 앱을 연다
- **THEN** 시스템은 현재 위치 반경 1km 안의 식당을 거리순으로 목록에 표시한다

#### Scenario: 거리 표시
- **WHEN** 목록에 식당이 표시된다
- **THEN** 각 항목은 식당 이름, 카테고리, 현재 위치로부터의 거리를 보여준다

### Requirement: 목록 추가 불러오기
시스템은 한 번에 표시한 결과보다 더 많은 식당이 있을 때 사용자가 다음 결과를 불러올 수 있게 해야 한다(SHALL).

#### Scenario: 더 보기
- **WHEN** 사용자가 목록 끝에서 "더 보기"를 선택하고 다음 결과가 존재한다
- **THEN** 시스템은 기존 목록 뒤에 다음 식당들을 이어서 표시한다

#### Scenario: 마지막 결과
- **WHEN** 더 불러올 결과가 없다
- **THEN** 시스템은 "더 보기"를 표시하지 않는다

### Requirement: 위치를 얻지 못했을 때의 처리
시스템은 위치 권한이 거부되거나 위치를 얻지 못해도 오류 없이 사용할 수 있어야 한다(SHALL).

#### Scenario: 위치 권한 거부
- **WHEN** 사용자가 위치 권한을 거부한다
- **THEN** 시스템은 위치를 사용할 수 없음을 안내하고, 키워드 검색으로 식당을 찾을 수 있음을 알려준다

#### Scenario: 위치 조회 실패
- **WHEN** 위치 조회가 시간 초과 등으로 실패한다
- **THEN** 시스템은 실패 사유를 안내하고 다시 시도할 수 있게 한다

### Requirement: 결과 없음과 오류 안내
시스템은 주변에 식당이 없거나 외부 서비스 호출이 실패했을 때 사용자에게 상태를 알려야 한다(SHALL).

#### Scenario: 주변 식당 없음
- **WHEN** 반경 안에 식당이 하나도 없다
- **THEN** 시스템은 "주변에 식당이 없어요"와 같은 안내를 표시한다

#### Scenario: 외부 서비스 호출 실패
- **WHEN** 식당 데이터를 불러오는 중 네트워크 오류나 서비스 오류가 발생한다
- **THEN** 시스템은 오류를 안내하고 다시 시도할 수 있게 한다

### Requirement: 로딩 상태 표시
시스템은 위치나 식당 데이터를 불러오는 동안 로딩 중임을 표시해야 한다(SHALL).

#### Scenario: 불러오는 중
- **WHEN** 위치 또는 식당 목록을 불러오는 중이다
- **THEN** 시스템은 로딩 표시를 보여주고, 완료되면 제거한다
